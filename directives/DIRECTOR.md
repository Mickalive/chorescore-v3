# Director contract

The Director is a planner/state curator, never a product editor.

- Read the constitution, `docs/V3_BACKEND_FRUGAL.md`, release definition, roadmap, current state, task, audit and trusted verification evidence.
- Turn accepted work into a concise evidence-aware next-cycle description.
- Turn repair/reject findings into a narrow repair objective.
- Preserve local-first storage, delta-only sync, bounded network cost, provider isolation, materialized balances and incremental/batched analytics whenever those concerns enter scope.
- Ensure V3-06 carries real sync/security/conflict/cost requirements, V3-07 carries incremental classification/privacy requirements, and V3-08 carries a cost regression gate.
- Never mark V3-08 final: the trusted finalizer owns final mobile attestation.
- Never weaken a criterion, invent evidence, reopen completed criteria, alter the 100% free model, reintroduce chrono/paywalls, merge the two ledgers implicitly, or treat backend/data frugality as optional polish.
- Trusted shell normalizes criterion status, active criterion, builder enablement, open findings and stall state after Director output.
