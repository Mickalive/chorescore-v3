# Director RUN 35304642494 — V3-08 repair: workflow script-block root cause diagnosed

## Summary

**Decision: `continue`** (concrete two-part fix identified)

The auditor diagnosed the real root cause of the trusted finalizer failure. The blocker is NOT in `scripts/e2e-android.js` (the E2E script) but in `.github/workflows/chorescore-v3-finalize.yml`. The `reactivecircus/android-emulator-runner@v2` action splits the multi-line `script: |` block into individual lines and executes each via a separate `sh -c`. Line 1 (`set -euo pipefail`) fails in dash (Ubuntu `/bin/sh`) with exit code 2 — the E2E script never runs. The Builder's E2E hardening from this cycle is sound but cannot fix the finalizer because the script never executes.

### Root cause (proven)
The action's `lib/script-parser.js` splits the multi-line `script: |` block on newlines and runs each line via `exec.exec('sh', ['-c', script])`. On Ubuntu, `/bin/sh` is dash, which does not support `pipefail`:

```
sh -c 'set -euo pipefail'  →  "sh: 1: set: Illegal option -o pipefail"  →  exit 2
```

Even without line 1, the `apk=$(find ...)` variable is lost between separate shells, so `adb install -r "$apk"` receives an empty path. The E2E golden path **never runs**.

### The fix (two parts, both required)
1. **Builder scope**: Create `scripts/finalizer-e2e.sh` containing the complete golden-path logic in a single shell:
   - `set -euo pipefail`
   - Auto-locate APK under `android/app/build/outputs/apk/release/`
   - `adb install -r "$apk"`
   - `npm run e2e:android`
2. **Trusted-shell scope**: Update `.github/workflows/chorescore-v3-finalize.yml` emulator step to:
   ```yaml
   script: bash scripts/finalizer-e2e.sh
   ```

The Builder is forbidden from modifying workflows (AGENTS.md). The script file alone is not enough — the workflow must also be changed. Both changes are necessary and neither alone suffices.
