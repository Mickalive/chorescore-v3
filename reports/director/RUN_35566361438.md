## Summary

The audit accepted the V3-08 repair cycle. The candidate fixes the per-relaunch kill loop that caused 16 consecutive trusted finalizer emulator E2E failures. After a force-stop + relaunch (crash detector or stuck detector), the relaunched app needs a fresh cold-start window (documented worst case 240s on API 35 x86_64), but the previous cold-start grace period (`COLD_START_GRACE_MS`, tied to `waitStart`) has already elapsed — the stuck-app detector immediately counts empty dumps against the fresh cold start and force-stops again, an infinite kill loop. The fix adds `FORCE_STOP_RECOVERY_MS = 300s`: every force-stop path records a timestamp, and stuck detection only resumes once 300s have elapsed since the last force-stop. The delta is confined to `scripts/e2e-android.js` and its contract test — zero product code changed, so V3-01 through V3-07 invariants are preserved.

## Why this fixes the blocker

The previous cycle added `COLD_START_GRACE_MS = 300s` covering the **initial** cold start (tied to `waitStart`). After a force-stop + relaunch mid-golden-path, the grace period has already elapsed. The stuck detector immediately counts empty dumps (STUCK_APP_THRESHOLD=4 = 2–4 min) and force-stops again → infinite kill loop → 16 consecutive finalizer failures at step 7.

The recovery window closes this gap:
- `FORCE_STOP_RECOVERY_MS = 300s` ≥ documented 240s cold-start worst case
- `globalThis._lastForceStopTime = Date.now()` recorded at every force-stop path
- Stuck detection increments `consecutiveEmptyMatchCount` **only** when `sinceLastForceStop >= FORCE_STOP_RECOVERY_MS`
- Crash detector (pidof check) remains active throughout the recovery window
- After recovery, normal stuck detection resumes

9-scenario simulation confirms:
- Healthy 240s/350s cold starts → 0 force-stops, found
- Healthy 550s cold start → exactly 1 force-stop then found at 555s (previously: second force-stop at ~660s > 600s timeout)
- Crash mid-path + healthy 240s cold start → found, no kill loop
- Genuinely stuck app → still force-stopped, bounded by timeout
