## Must-fix findings → next task

**Finding 1 (mustFix) — Balances history rows are non-interactive**

`app/(tabs)/balances.tsx` lines 894–917: each `historyRow` renders `formatActivityRow(...)` inside a plain `Text` with `numberOfLines={2}`. No `onPress`, no action buttons, no navigation to edit, no delete confirmation, no share invocation.

Required fix: make each history row pressable and open an action sheet/modal with **Edit**, **Delete**, **Share**:
- **Edit** → navigate to `add.tsx` in edit mode, pre-filled with the entry's data.
- **Delete** → confirmation alert (`t('add.deleteConfirm')`), then `repos.contributions.delete(id)` or `repos.expenses.delete(id)`, then `emitDataChange` so the materialized balances refresh via delta.
- **Share** → `services.share.share({ message: formattedLine })` reusing `share.taskLine` / `share.expenseLine`.
- Preserve paginated loading, delta refresh and zero-sum invariants.

**Finding 2 (mustFix) — Add screen lacks edit mode**

`app/(tabs)/add.tsx` only supports creation. The keys `add.editBanner`, `add.update`, `add.errorEdit`, `add.errorDelete` exist in the catalog but are unused.

Required fix: add edit mode to `add.tsx`:
- Accept route params (`entryId`, `entryType: 'task' | 'expense'`).
- When editing: fetch via `repos.contributions.getById` / `repos.expenses.getById`, pre-fill all form fields, show `add.editBanner` title, use `add.update` button text.
- On submit: `repos.contributions.update(id, data)` / `repos.expenses.update(id, data)` with `modifiedBy` set.
- Preserve all existing create functionality (mode switch, categories, members, photos, splits, ratios).

**Finding 3 (mustFix) — Missing i18n keys for history actions**

`src/i18n/catalog.ts` has no keys for the Balances history action sheet or its confirmations.

Required fix — add to both FR and EN:
- `balances.editEntry` / `balances.deleteEntry` / `balances.shareEntry`
- `balances.deleteConfirmTask` / `balances.deleteConfirmExpense`
- `balances.editTask` / `balances.editExpense`

French formulations must be correctly accented (e.g. `Modifier la tâche`, `Supprimer cette dépense`, `Partager`). `i18n:check` must stay green (identical key sets, no forbidden wording).
