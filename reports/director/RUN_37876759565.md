### Honest gap analysis (grounded in source)

- **Delta-only sync is real but incomplete.** `SYNC_COLLECTIONS` in `src/domain/services/syncEngine.ts` currently covers only `contribution_entries`, `expense_entries`, `settlements`, `todo_items`, `persistent_tasks`, `members`, `memberships`, `households`. User-created **categories**, **invitations** and **photo/attachment metadata** are not sync collections, and `SyncMaterializer` has no materialize/delete case for them. V4-07 must extend the same per-group cursor/revision/tombstone protocol to them — no full-collection downloads, no per-render network reads.
- **Privacy foundation exists and must be extended, not rebuilt.** `src/domain/services/attachmentService.ts` already exposes `attachmentReleaseDescriptor` (metadata-only, no `id`/`ref`) and `normalizeNote`; the V3-07 pipeline already rejects free text (`title`, `notes`, `note`, `categoryLabelSnapshot`), attachment payloads (`attachments`, `attachmentRefs`, `photoRefs`) and the operational `categoryId`. V4-07 must make category normalization a downstream-only step and keep notes/photos/raw labels out of any release payload.
- **Photos must stay lazy.** Opening a group or Balances must not bulk-download photo bytes or history; metadata is bounded and references never cross the operational boundary.
- **Conflicts are deterministic.** `resolveConflict` (revision → timestamp → id) already exists and is applied across collections; V4-07 must preserve and test that for the newly added collections (concurrent add/edit/delete, offline-return, invite-accepted-during-changes).
- **Tenant isolation must be enforced server-side.** IDs/fields supplied by the client are never trusted; membership/permission checks gate every collection.
- **Cost gate must be extended.** The current `cost:check` runs only the V3-08 gate suite. V4-07 must extend regression coverage to categories, members, invitations, notes/photos and todo-expense (bounded reads on group open, zero reloads on tab switch, bounded delta/writes, no redundant classification).
- No V4-07 test suite exists yet; a focused V4-07 regression suite is required.
