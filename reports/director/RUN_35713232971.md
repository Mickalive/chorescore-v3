## Summary

V3-08 repair accepted. The candidate fixes the trusted finalizer E2E blocker from Actions run 35709623336: the `SyncRecordingWrapper` seed fire-and-forget race that left the app on "Aucun groupe" forever on device, blocking the golden path.

### Root cause

All 8 `SyncRecording*Repository` wrappers exposed:

```ts
seed(items: T[]): void { this.inner.seed(items); }
```

discarding the inner `Promise`. `ensureDemoFixture` does `await repos.households.seed` → `await repos.memberships.seed` → `await repos.members.seed` then immediately performs a membership-checked read (`tasks.getByHousehold` → `checkMembership` → `memberships.getByHousehold`). On device the SQLite repositories are genuinely async (INSERTs `await`ed); awaiting `void` resolved instantly while the INSERTs were still in flight, so the read saw `[]` and threw `CROSS_TENANT`. On-device symptom: *signed in but "Aucun groupe" forever* — the golden path never reaches **Ajouter / Balances / À faire** and the finalizer times out. InMemory repos are synchronous, which is why CI (468 tests) stayed green while the finalizer failed.

### Fix

Every wrapper now awaits the inner seed:

```ts
async seed(items: T[]): Promise<void> { await this.inner.seed(items); }
```

`await undefined` (InMemory) still resolves immediately, so backward compatibility is retained. `SeedableRepository` already allows `Promise<void>|void`, so the change is interface-compatible.
