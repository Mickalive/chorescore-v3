- **Cold-start grace** 300s → 450s: beyond the documented 240s cold start, within the 900s Demarrer timeout

- **Boot timeout** 300s → 420s: documented 120–240s boot + CI load
- **Settle** 15s → 30s: full runtime initialization after `sys.boot_completed=1`
