## What happened

### Root cause (unchanged from cycle 35310569665)

The `reactivecircus/android-emulator-runner@v2` GitHub Action splits a multi-line `script: |` block into separate `sh -c` invocations. In dash, `set -euo pipefail` is not supported and exits with code 2. Variables assigned in one line are lost in the next. This causes the finalizer to fail before any E2E logic runs.

### Builder-side fix (already completed)

`scripts/finalizer-e2e.sh` (35 lines) exists and contains the complete golden-path logic in a single bash process:
- `set -euo pipefail`
- APK auto-location with empty/missing guard
- `adb install -r "$apk"`
- `npm run e2e:android`

This script was created in cycle 35310569665 and accepted by the auditor. It has not been modified.

### This cycle (35317911890)

- No product delta produced (hasDelta=false).
- Audit decision: repair.
- The workflow file `.github/workflows/chorescore-v3-finalize.yml` was inspected. Lines 90-94 still contain:
  ```yaml
  script: |
    set -euo pipefail
    apk=$(find android/app/build/outputs/apk/release -type f -name '*.apk' | head -1)
    adb install -r "$apk"
    npm run e2e:android
  ```
- The mandated change — replacing this with `script: bash scripts/finalizer-e2e.sh` — was **not applied**.
- The Builder is forbidden from modifying workflow files (AGENTS.md). This change belongs exclusively to the trusted shell.

## What the trusted shell must do

1. **Update the workflow**: in `.github/workflows/chorescore-v3-finalize.yml`, replace the emulator step's `script: |` block (lines 90-94) with:
   ```yaml

   ```
2. **Commit and push** the workflow change to `lab/chorescore-v3`.
3. **Re-run the trusted finalizer** (Actions workflow_dispatch or next scheduled run).
4. The finalizer must confirm:
   - Product, privacy, and cost gates pass.
   - Release APK builds and is non-empty.
   - `bash scripts/finalizer-e2e.sh` executes in a single process on the API 35 emulator.
   - `adb install` succeeds.
   - `npm run e2e:android` traverses the golden path (login → groups → tabs → add → balances → todos → back-to-add).
5. Only after the finalizer succeeds: **mark V3-08 as `complete`** in `docs/RELEASE_STATUS.json`.
