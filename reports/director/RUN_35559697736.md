## Why this fixes the blocker

The stuck-app detector force-stopped the app after 4 consecutive empty uiautomator dumps (2–4 min on a loaded API 35 x86_64 emulator), but React Native cold start can reach 240s. The detector was killing a healthy app mid-start, resetting the cold start each cycle → infinite kill loop → 15 consecutive finalizer failures at the same step.

The grace period (300s ≥ documented 240s worst case, ≤ 600s Demarrer timeout) suppresses the counter during cold start. After grace, stuck detection resumes normally. The pidof crash detector remains active throughout.
