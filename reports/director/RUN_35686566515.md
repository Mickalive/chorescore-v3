### Root cause

On degraded API 35 x86_64 emulators, each uiautomator dump takes 30-60s. The stuck-app detector fires after `COLD_START_GRACE_MS` (450s) plus 8 consecutive empty dumps × 30-60s = **690-930s worst case**. The previous 900s timeout expired before the detector could fire in the 60s-dump scenario (930s), so the force-stop + relaunch recovery never ran inside the `waitFor`.

### Fix
