- **`scripts/boot-emulator.sh`** — **new** self-contained emulator boot script: installs SDK packages, creates the AVD
  (API 35, x86_64, pixel_6), launches headless (`-no-window -gpu swiftshader_indirect -no-snapshot -noaudio

  AND `input` services with live round-trips; `wait_android_services()` requires package/activity/input/settings
  registration **AND** a live probe; Metro cache clearing around the E2E-flagged rebuild; diagnostic echoes on failure.
- **`__tests__/domain/v3-08-finalizer-wrapper.test.ts`** — **modified**: three static contract tests (live input
  round-trip probe, emulator-ownership fallback, `boot-emulator.sh` contract), pure static guards runnable in plain CI.
