## Summary

V3-08 repair accepted. The candidate repairs the trusted finalizer E2E blocker from Actions run 35720925070: the demo-fixture history ordering made `Vaisselle du soir` invisible to the golden-path `waitFor`, timing out the finalizer even though all product gates were green.

### Root cause

`src/features/app/demoFixture.ts` seeded:

- `Vaisselle du soir` → `Date.now() - 2d`
- `Courses Migros` → `Date.now() - 1d`

so **Courses** was the most recent entry. The Ajouter history is sorted `occurredAt DESC` (`paginateActivityLog`, `src/domain/calculations/activityLog.ts`). The E2E golden path in `scripts/e2e-android.js:1072` does:

```js
waitFor('Vaisselle du soir', 300000) // visible nodes only, no scroll
```

`waitFor` → `dumpUi` → `findNodes` filters only uiautomator-visible nodes inside the current viewport. On the `pixel_6` API 35 emulator the second history row is off-screen, so `Vaisselle du soir` never became visible → `waitFor` timed out → the finalizer job failed despite green `npm test` / `privacy:check` / `cost:check` and a successful `assembleDebug` build.

### Fix

1. **`src/features/app/demoFixture.ts`** — swapped the timestamps with an explanatory comment: `Vaisselle du soir` now `-1d` (most recent, first visible row), `Courses Migros` now `-2d`.
2. **`__tests__/domain/v3-08-e2e-golden-path.test.ts`** — added regression test `2b` asserting `dishes.occurredAt > groceries.occurredAt`, which fails on the old ordering and passes now. The remaining golden-path tests (contribution, expense, balances, settlement, todo atomic, edit/delete, activity log DESC, invitation, sync delta) still pass 13/13.
