## Must-Fix Finding

- The error condition `[ "$INSTALL_ATTEMPTS" -ge "$MAX_ATTEMPTS" ]` is true both when all 3 attempts fail AND when the install succeeds on the final (3rd) attempt.
- A success on the last retry prints "APK installed successfully on attempt 3" and then still reports "ERROR: APK install failed after 3 attempts" and exits 1.
- This directly defeats the purpose of the retry: the exact transient-flake scenario the repair targets (first attempts fail, last attempt succeeds) would still fail the trusted finalizer.

**Required fix:** Track install success explicitly with a flag (e.g. `INSTALLED=1` after successful `adb install -r` before `break`), and change the error branch to `if [ "${INSTALLED:-0}" -ne 1 ]; then ... exit 1; fi`.
