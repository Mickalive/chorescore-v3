## Root cause (confirmed)

`reactivecircus/android-emulator-runner@v2` does **not** execute the `script:` input as one shell. Its `lib/script-parser.js` splits the input into individual lines (trimmed, comments/empty dropped) and `lib/main.js` executes **each line** via `exec.exec('sh', ['-c', script])`.

The workflow's emulator step (`.github/workflows/chorescore-v3-finalize.yml` lines 84–94, unchanged on `main` since creation — `git log` shows only `3f14a90` and `8b245b2`) is:

```yaml
script: |
  set -euo pipefail
  apk=$(find android/app/build/outputs/apk/release -type f -name '*.apk' | head -1)
  adb install -r "$apk"
  npm run e2e:android
```

The action therefore runs `sh -c "set -euo pipefail"` first. On Ubuntu `/bin/sh` is dash, which rejects `pipefail`:

```
$ sh -c 'set -euo pipefail'
sh: 1: set: Illegal option -o pipefail
dash exit: 2
$ bash -c 'set -euo pipefail'
bash exit: 0
```

The step fails with exit 2 **before** the APK install and golden path ever run. This is the exact failure mode of runs 35293489693, 35302658175 and 35315519533.
