## V4-09 Strategy Changes Implemented

The finalizer surface now implements concrete strategy changes per V4_RELEASE_ENGINEERING.md §7 ("une répétition identique sans nouvelle preuve doit changer de stratégie, pas seulement augmenter les timeouts"):

### 1. Emulator Ownership (`boot-emulator.sh`)
- Repository owns the emulator lifecycle; `finalizer-e2e.sh` calls `boot-emulator.sh` when no device is attached.
- Workflow can drop the fragile `reactivecircus/android-emulator-runner@v2` action step.

### 2. Live Framework Service Readiness Gate
- `wait_android_services()` / `live_probe()` require:
  - ADB state = `device`
  - `service check package/activity/input/settings` all return `found`
  - **Real round-trip**: `settings get system screen_off_timeout` returns a value
  - **Real round-trip**: `input keyevent 0` (KEYCODE_UNKNOWN) succeeds
- `sys.boot_completed=1` alone is explicitly rejected as insufficient.

### 3. Active ADB Transport Recovery
- `recover_adb_transport()` on broken-pipe signature:
  1. `adb reconnect offline`
  2. `adb wait-for-device`
  3. If still dead: `adb kill-server` → `adb start-server` → `adb wait-for-device`
- Bounded retries (4 in boot-emulator.sh, 1 re-gate in finalizer-e2e.sh).

### 4. Extended Boot Timeout
- `EMULATOR_BOOT_TIMEOUT=900` (was 600) to accommodate 498s observed boot.

### 5. Bounded ANR Handling (`e2e-android.js`)
- `dismissAnrOverlay()` distinguishes:
  - **App ANR** (dialog names "ChoreScore" or package `app.chorescore.v3`) → tap Wait → force-stop + relaunch
  - **Infra ANR** (Quickstep, SystemUI, system, phone) → tap Wait → re-assert foreground **without** force-stop
- Prevents the infinite kill loop observed in run 37946700758.

### 6. Metro Cache Clearing for E2E Rebuilds
- `clear_metro_cache()` evicts transform cache keyed independently of `EXPO_PUBLIC_*` env vars.
- E2E rebuild deletes bundle outputs (`generated`, `intermediates/assets`, `merged_assets`, release APKs) before `gradlew assembleRelease -PreactNativeArchitectures=x86_64`.
- Post-E2E, same outputs cleared so arm64 release build re-bundles **without** E2E session.

### 7. Keyguard Dismissal & Error Dialog Suppression
- `dismiss_keyguard()`: 5 bounded attempts with `input keyevent 82` + `wm dismiss-keyguard` + verification via `dumpsys window`.
- `suppress_error_dialogs()`: sets `hide_error_dialogs=1` globally so SystemUI/launcher ANR dialogs never steal focus.
