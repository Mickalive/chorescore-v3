## Repair Details (vs. Pristine Baseline)

| Area | Change |
|------|--------|
| **`scripts/finalizer-e2e.sh`** | Added `framework_cmd_ready()` — probes a real `settings get system screen_off_timeout` round-trip; treats broken pipe / not-found / error as not-ready. Extended `wait_android_services()` to require `input` and `settings` service registration **and** the liveness probe. Added `dismiss_keyguard()` — bounded (5 attempts) re-assertion of screen unlock via `input keyevent 82` + `wm dismiss-keyguard` with `dumpsys window` verification; best-effort (never fails the step). Called before install/launch. |
| **`__tests__/domain/v3-08-finalizer-wrapper.test.ts`** | New test `wrapper gates on input/settings services and re-dismisses the keyguard` verifying the above repairs. |

These changes address the concrete failure mode observed in run 37909577314: right after `sys.boot_completed=1`, the emulator-runner action's own `input keyevent 82` and `settings put` returned `cmd: Failure calling service input/settings: Broken pipe (32)`. Service registration alone did not catch a framework still initializing; the wrapper now requires a live round-trip and re-dismisses the keyguard before the golden path.
