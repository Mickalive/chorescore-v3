## Risk Assessment

| Risk | Mitigation |
|------|------------|
| E2E session leaks into release APK | Finalizer clears Metro cache + deletes bundle outputs before arm64 build; `EXPO_PUBLIC_E2E_AUTH` only set during explicit x86_64 rebuild |
| Flaky UI automation on slow emulator | 1260s cold-start grace (73s headroom), 300s per-screen waits, testID-based (not text-based) targeting, scroll retries |
| Metro cache key ignores env vars | `clear_metro_cache()` called before flagged rebuild and before arm64 build |
| Forbidden label false positives | `assertAbsentExact` for short tokens (`Pro`/`Standard`/`Premium`); substring for longer (`abonnement`/`paywall`/`Contribution`) |
