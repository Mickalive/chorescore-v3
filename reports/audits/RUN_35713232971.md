## Summary

**ACCEPT** V3-08 repair cycle 35713232971. The candidate repairs the trusted finalizer E2E blocker from Actions run 35709623336 while preserving V3-01..V3-07.

Root cause is a fire-and-forget `seed()` in `SyncRecordingWrapper`. All 8 wrappers previously did:

```ts
seed(items: T[]): void { this.inner.seed(items); }
```

discarding the inner `Promise`. `ensureDemoFixture` does `await repos.households.seed` → `await repos.memberships.seed` → `await repos.members.seed` then immediately does a membership-checked read (`tasks.getByHousehold` → `checkMembership` → `memberships.getByHousehold`). On device the SQLite repositories are genuinely async (INSERTs `await`ed); awaiting `void` resolved instantly while the INSERTs were still in flight, so the read saw `[]` and threw `CROSS_TENANT`. On-device symptom: *signed in but “Aucun groupe” forever* — the golden path never reaches **Ajouter / Balances / À faire** and the finalizer times out. InMemory repos are synchronous, so CI (468 tests) stayed green while the finalizer failed.

Fix makes every wrapper `async` and `await` the inner seed:

```ts
async seed(items: T[]): Promise<void> { await this.inner.seed(items); }
```

`await undefined` (InMemory) still resolves immediately, so backward compatibility is retained. The delta is exactly **2 files** (`SyncRecordingWrapper.ts` 8 lines, `sync-recording-seed.test.ts` +194 lines / 9 tests). No other product code, governance, directives, docs or workflows changed. No ledger, sync protocol, analytics, privacy, theme, chrono or premium change — V3-01..V3-07 remain byte-identical to pristine except for this single `await` fix.

Trusted verification is fully green: typecheck clean, **468 tests / 23 suites** (was 459), privacy **71** PASS, cost **21** PASS, `expo export --platform android` OK (3.2 MB), `expo prebuild --platform android` OK, `gradlew :app:assembleDebug` **BUILD SUCCESSFUL** in 18m41s. Independent `npm test`, `privacy:check`, `cost:check`, `tsc --noEmit`, grep checks for chrono/premium/Firebase, and cost/privacy gates all pass. No `mustFix` remains. The trusted shell must re-dispatch the trusted finalizer to exercise the corrected demo-fixture path on a real API 35 emulator with SQLite; if it passes product, privacy, cost, APK build, install/launch and golden-path evidence, V3-08 can be marked `complete`.

## Findings

### 1. `src/infrastructure/sync/SyncRecordingWrapper.ts` — seed fire-and-forget (repaired) — `mustFix: false`

- **Problem:** All 8 SyncRecording wrappers exposed `seed(items): void { this.inner.seed(items); }` discarding the inner Promise. Callers (`ensureDemoFixture`, `SyncMaterializer`) `await` the call but `await undefined` resolves instantly while SQLite async INSERTs were still in flight. The fixture then performed a membership-checked read that saw empty state and threw `CROSS_TENANT` — on device the app stayed on “Aucun groupe” forever, blocking the golden path (install/launch/E2E).
- **Evidence:** pristine grep shows 8× `seed(...[]): void { this.inner.seed(items); }`; `SqliteRepositories` seeds are `async` (`await db.runAsync…`), `InMemory` are sync; `demoFixture.ts:26,32,45,63` `await seed` then `await repos.tasks.getByHousehold` → `checkMembership` → `memberships.getByHousehold`; `TRUSTED_35713232971.md` 468 tests pass only after fix; candidate diff changes 8 lines to `async seed(...): Promise<void> { await this.inner.seed(items); }` and adds 9 tests that would fail on old code (wrapper returns `undefined` not `Promise`, resolves before inner completes).
- **Required fix:** Fixed in this candidate — all 8 wrappers now `async` and `await` inner. No further fix needed.
- **Verification:** `npm test` 468/468 pass incl `sync-recording-seed` 9/9; `privacy:check` PASS; `cost:check` PASS; `tsc --noEmit` clean; `TRUSTED_35713232971.md` BUILD SUCCESSFUL 18m41s; InMemory compatibility retained (`await void` resolves immediately).
