- **Named member invitation links same memberId without duplicate** — `invitationService.ts` creates invitations with `targetMemberId`; `planInvitationAcceptance` validates the exact member and returns `linksExistingMember: true` so the caller updates the existing member's `userId` instead of creating a new one.
