# Audit RUN 35310569665 — V3-08 repair: single-shell finalizer E2E wrapper

## Decision: `accept`

The candidate delivers exactly the Builder-scoped half of the two-part repair mandated by the open findings: a new `scripts/finalizer-e2e.sh` that runs the complete golden-path logic in a **single bash process**, so the `reactivecircus/android-emulator-runner@v2` line-splitting defect can no longer break the finalizer step.

## Context

The trusted finalizer failed twice (runs 35293489693 and 35302658175) at step 7 with annotation `The process /usr/bin/sh failed with exit code 2`. Root cause (proven in cycle 35304642494): the action splits the multi-line `script: |` block into individual lines and executes each via its own `sh -c`. On Ubuntu, `/bin/sh` is dash, which rejects `set -euo pipefail` (exit 2), and shell-local variables like `apk=$(find ...)` are lost between lines. The E2E golden path never ran.

The repair is two-part:

1. **Builder scope (this cycle):** create `scripts/finalizer-e2e.sh` with the install + golden-path logic in a single shell.
2. **Trusted-shell scope (next cycle):** change the workflow's emulator step to `script: bash scripts/finalizer-e2e.sh` and re-run the finalizer.

The Builder is forbidden from modifying workflows (AGENTS.md). The candidate correctly leaves `.github/workflows/chorescore-v3-finalize.yml` untouched.
