## Summary

The candidate repairs the V4-09 finalizer blocker by fixing a stale UI dump cache in the E2E test harness (`scripts/e2e-android.js`). The failure in run 38044668252 was a **false negative**: the product correctly accepted the typed input (`alex` into the member name field), but the verification read a cached UI dump captured *before* typing — on this React Native / Android API 35 build, an empty `EditText` reports its placeholder as `text`, so the readback saw `"Nom du membre"` instead of the actual value.

The fix invalidates `_dumpCache = null` immediately after `inputKeyText(value)` in three text-input helpers:
- `typeInto` (label-based)
- `typeIntoTestId` (testID-based)
- `typeIntoTestIdNth` (nth testID match)

A regression test in `__tests__/domain/v3-08-finalizer-wrapper.test.ts` verifies the fix is present and cites the evidence run.

All trusted verification gates pass. The V4-09 domain feature (targeted invitation links the same named member, no duplicate, preserves ledger history) was already implemented and covered by `__tests__/domain/v4-09-invitation-linkage.test.ts` (5 tests passing). No regression of V4-01..V4-08 or V3 foundations.
