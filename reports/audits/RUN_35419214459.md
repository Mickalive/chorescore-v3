## 6. MUST-FIX finding

- **Path:** `scripts/finalizer-e2e.sh` (install retry loop, lines 64-86).
- **Problem:** off-by-one in the retry loop. The error condition `[ "$INSTALL_ATTEMPTS" -ge "$MAX_ATTEMPTS" ]` is true both when all 3 attempts failed **and** when the install succeeds on the final (3rd) attempt (INSTALL_ATTEMPTS is incremented to 3 before the successful attempt breaks). A success on the last retry prints "APK installed successfully on attempt 3" and then still reports "ERROR: APK install failed after 3 attempts" and exits 1. This defeats the purpose of the retry added to fix blocker (b): the exact transient-flake scenario the repair targets would still fail the trusted finalizer with a misleading error.
- **Evidence:** simulation above; `bash -n` passes (logic defect, not syntax).
- **Required fix:** track success explicitly — set `INSTALLED=1` immediately after the successful `adb install -r "$apk"` before `break`, and change the error branch to `if [ "${INSTALLED:-0}" -ne 1 ]; then ... exit 1; fi`. Keep the existing diagnostics in the error branch. Do not change the boot-wait, diagnostics or golden-path parts, which are correct.
- **Verification:** re-run the loop simulation for all permutations — `(1,1,0)` must continue to the golden path with exit 0; `(1,0)` and `(0)` must continue with exit 0; `(1,1,1)` must print ERROR and exit 1. Then `bash -n` and the finalizer-wrapper suite (6/6) must stay green, and the trusted finalizer must pass the Android API 35 emulator step with exit 0.
